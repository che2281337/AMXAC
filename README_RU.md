# AMXAC

Модульный серверный античит для Counter-Strike 1.6.

- AMX Mod X 1.9+ с модулями `fakemeta`, `hamsandwich`, `nvault`.
- ReAPI нужен только для `amxac_antiesp` (защита от звукового ESP); всё остальное работает и на обычном HLDS.

## Как работает

Детекторы сами никого не банят. Каждое подозрительное действие добавляет игроку очки, очки со временем сгорают (по умолчанию вдвое за 2 минуты), а сумма запускает уровни:

| Уровень | Очки | По умолчанию |
|---|---|---|
| WARN | 30 | запись в лог |
| ALERT | 60 | сообщение админам в чат |
| ACTION | 100 | действие из `amxac_punish_action` (по умолчанию `none`) |

Для каждого уровня выбираешь `none`, `mute`, `kick` или `ban`. Кик и бан откладываются до конца раунда, чтобы читер не понял, на чём спалился; выход с сервера от запланированного бана не спасает. Бан идёт через твою систему банов (`amxac_punish_ban_cmd`) или через `banid`/`addip` движка.

Каждый детектор — отдельный модуль со своим весом `amxac_w_<имя>` (0 = выключен). Всё пишется в `logs/amxac_ГГГГММДД.log` с ником, SteamID и IP.

## Плагины

| Плагин | Что делает |
|---|---|
| `amxac_core` | очки, уровни, логи, уведомления админам, API для своих модулей |
| `amxac_antiwh` | не отправляет игроку врагов, которых он не видит (WH, радар); пока игрок полностью ослеплён, не отправляет врагов вообще (no-flash) |
| `amxac_antiesp` | шаги и другие звуки невидимых врагов слышны с правильного направления и громкости, но не с настоящего места; события выстрелов скрыты от тех, кто стрелка не видит (**ReAPI**) |
| `amxac_aim` | **silentaim** (рывок на выстреле с точным возвратом), **aimsnap**, **trigger** (мгновенная или «ровная» реакция), **tracking** (прицел на враге за стеной, залипание, % хедшотов), **nospread**, **norecoil**, **knifebot**, **fastzoom**, **rapidfire**, **noflash** (прицельные попадания вслепую) |
| `amxac_move` | скрипты **bhop** и **sgs** (идеальные прыжки/дактапы), **макросы** прыжка/приседа (AHK-таймеры), **strafe** (автострейф, хелпер), **speedhack**, пустые команды с `msec 0`, **angles** (anti-aim, спинбот), **netcode** (fakelag, lag shot), **movecheck** (движение, которое не может прислать настоящий клиент) |
| `amxac_misc` | флуд сменой ника, игроки с одного IP, правила кваров (`amxac_cvars.ini`), блокировщики запросов кваров, история нарушений по SteamID, кик за дубль SteamID, чёрный список IP/подсетей |
| `amxac_punish` | мут / кик / бан по уровням, отложенные и офлайн-баны, свои команды бана/кика и тексты в чат |
| `amxac_ghost` | ловушка: админ становится невидимым; ESP его всё равно рисует, а аимбот наводится, поэтому тот, кто стреляет в него или ведёт его прицелом, попадается |
| `amxac_selftest` | **только для теста**: имитирует поведение читов на твоих собственных usercmd, чтобы проверить детекторы |

## Модули

У каждого модуля свои очки и вес `amxac_w_<модуль>`; пороги — в `amxac.cfg`.

| Модуль | Плагин | Ловит | Как |
|---|---|---|---|
| `antiwh` | antiwh | WH, ESP, радар | Предотвращение: враг отправляется игроку, только если трассировка от его глаз доходит до головы, тела, боков или ног врага (с поправкой на пинг). Видимость закрывает только геометрия карты; увиденный враг остаётся видимым ещё 0.3 с. Бюджет трассировок в секунду, при перегрузке показывает всех |
| *(анти-noflash)* | antiwh | no-flash | Предотвращение: пока экран игрока полностью белый после флешки, враги ему не отправляются |
| `antiesp` | antiesp | звуковой ESP, звуковой радар | Предотвращение (ReAPI): звуки врагов, которых игрок не видит, идут от мира с подставного расстояния с пересчитанной громкостью — направление и громкость верные, место нет. События выстрелов получают только те, кто видит стрелка или место попадания |
| `silentaim` | aim | pSilent | Рывок ≥15° на кадре выстрела, держится 1–2 кадра, затем возврат к старому углу с точностью 1° / 10%. Учитывает и «сырой» `+attack`, поэтому работает и за Unreal Aim Blocker |
| `aimsnap` | aim | рывки аимбота (слабый) | Хедшот сразу после рывка ≥20°, на следующем кадре прицел замирает (≤0.3°) |
| `trigger` | aim | триггербот | Время от появления врага в прицеле до нового клика: ≥5 из 10 быстрее 15 мс, или 10 реакций с σ ≤ 8 мс (триггер с фиксированной задержкой) |
| `tracking` | aim | наводка через WH, плавный аимбот | Прицел на невидимом враге ≥600 мс со средней ошибкой ≤1.2° при движении мыши; залипание: σ ошибки прицела ≤0.25° при повороте вида ≥15°; ≥17 хедшотов из 20 последних убийств с огнестрела |
| `nospread` | aim | no-spread | Кадр выстрела отклонён от траектории мыши на величину разброса, а настоящая пуля (перехваченная трассировка) идёт точно по траектории — 8 из 10 выстрелов |
| `norecoil` | aim | no-recoil | `v_angle + punchangle` неподвижен (≤0.25°, ≤25% отдачи) всю очередь от 6 выстрелов |
| `knifebot` | aim | нож-бот | Первый удар быстрее 15 мс после входа врага в 64 юнита, 7 из 10 раз |
| `fastzoom` | aim | скрипт быстрого зума | Выстрел в зуме быстрее 40 мс после зума, 3 из 6 |
| `rapidfire` | aim | автокликер на пистолете | 12 кликов пистолетом с σ интервалов ≤ 2.5 мс |
| `noflash` | aim | no-flash | ≥3 попадания с новых нажатий по врагам за одно полное ослепление (хедшот за два) |
| `bhop` | move | бхоп-скрипт, макросы прыжка | 10 идеальных прыжков подряд, 6 «чистых» (без нажатий в воздухе), 80% из 30; прыжок ≥25 раз/с три секунды с ровным интервалом (AHK) |
| `sgs` | move | SGS / дактап-скрипт, макросы приседа | То же, что bhop, для `+duck` |
| `strafe` | move | автострейф, strafe-хелпер | `sidemove` без A/D на ≥50% кадров в воздухе; смена A/D ровно в кадр разворота мыши в ≥90% из 40 смен (у людей 20–40%) |
| `speedhack` | move | спидхак, пустые команды | Часы клиента (сумма `msec`) убегают вперёд сервера на ≥300 мс; пачки кадров с `msec = 0` |
| `movecheck` | move | movement-хаки | Движение против единственной нажатой клавиши или вектор движения длиннее `maxspeed`, до которой клиент его ужимает |
| `angles` | move | anti-aim, спинбот | Pitch за ±89.9°; yaw крутится быстрее 2000°/с две секунды |
| `netcode` | move | fakelag, lag shot | Регулярные пачки по 12+ «задушенных» кадров; выстрелы приходят в задушенных пакетах намного чаще остальных кадров (backtrack) |
| `misc` | misc | воровство ников, мультиаккаунт | ≥4 смены ника за 10 с; больше 3 игроков с одного IP |
| `cvars` | misc | ленивые читы, блокировщики запросов | Защищённые квары клиента из `amxac_cvars.ini`; запросы кваров без ответа, пока клиент продолжает играть |
| `history` | misc | рецидивисты | Кто уже доходил до ALERT, заходит с дополнительными очками (по SteamID, 30 дней) |
| `honeypot` | ghost | ESP, аимбот | Прицельные выстрелы с новых нажатий или ведение прицелом невидимого админа (`amx_ac_ghost`), которого честный игрок не видит |

Плюс прямые кики без очков: дубль SteamID (эмуляторы) и чёрный список IP/подсетей.

## Установка

1. Собрать `scripting/*.sma` с инклудами из `scripting/include/` (для `amxac_antiesp` нужны ещё инклуды ReAPI).
2. `.amxx` положить в `addons/amxmodx/plugins/`, строки из `configs/plugins-amxac.ini` добавить в `plugins.ini`. `amxac_core` первым; без ReAPI строку `amxac_antiesp` убрать.
3. `configs/ru/amxac.cfg` (русские комментарии) или `configs/amxac.cfg` (английские) положить как `addons/amxmodx/configs/amxac.cfg`, туда же `amxac_cvars.ini` и `amxac_blocked_ips.ini`.
4. Первую неделю держать все наказания на `none` и `amxac_notify_reports 1`, читать логи и подстраивать пороги. Потом включать наказания.

Каждая настройка прокомментирована в `amxac.cfg`.

**Типы серверов:**
- серверы с autobhop: `amxac_w_bhop 0`;
- KZ / бхоп-серверы: `amxac_w_sgs 0`, `amxac_w_strafe 0` или пороги выше — скролл и хорошие стрейфы там норма;
- нож-серверы: knifebot уже строгий, при необходимости снизь `amxac_w_knifebot`.

## Команды

| Команда | |
|---|---|
| `amx_ac_status [игрок]` | очки по игрокам / по модулям |
| `amx_ac_reset <игрок>` | сбросить очки |
| `amx_ac_modules` | модули и их веса |
| `amx_ac_punish <игрок> <kick\|ban\|mute>` | наказать сразу |
| `amx_ac_cancel <игрок>` / `amx_ac_unmute <игрок>` | отменить запланированное наказание / снять мут |
| `amx_ac_blockip` / `amx_ac_unblockip` / `amx_ac_blocklist` | чёрный список IP (`1.2.3.4` или `1.2.3.0/24`) |
| `amx_ac_ghost` | включить/выключить призрака-ловушку (ходи с Shift: шаги не заглушить) |
| `amx_awh_stats` | расход трассировок anti-WH |
| `amx_ac_test <режим\|list\|off> [игрок]` | режимы самопроверки |

`amxac_debug 1` пишет в консоль админам с флагом rcon, почему детектор сработал или нет.

## Проверка

Включи `amxac_selftest` на тестовом сервере (в `plugins.ini` выше `amxac_aim`/`amxac_move`), добавь ботов и включай по одному режиму: `silent`, `aim`, `trigger`, `wall`, `norecoil`, `knife`, `zoom`, `rapid`, `bhop`, `sgs`, `macro`, `strafe`, `speed`, `zero`, `movehack`, `pitch`, `spin`. Смотри `amx_ac_status` и лог; `amx_ac_test list` объясняет каждый режим.

## API

```pawn
#include <amxac>

new g_mod = amxac_register_module("mycheck");
amxac_report(id, g_mod, 10.0, "reason %d", value);
amxac_set_ignore(id, -1, 2.0);   // например, вокруг телепорта в твоём моде
```

Форварды `amxac_on_report` (верни `PLUGIN_HANDLED`, чтобы отбросить репорт) и `amxac_on_level`. Полный список в `scripting/include/amxac.inc`.

## Совместимость

- **Unreal Aim Blocker**: в списке плагинов ниже `amxac_aim` и `amxac_move`.
- **WHBlocker**: может заменить `amxac_antiwh` (`amxac_awh_enabled 0`, `amxac_awh_flash 1` оставить); `amxac_antiesp` работает с любым из них.
- **UNREAL_ANTI_ESP**: вместе с `amxac_antiesp` не ставить.
